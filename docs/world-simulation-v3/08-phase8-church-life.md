# 阶段 8：教会生活、教育与记录

状态：2026-10-06 完成。390 项单元测试、完整构建、两轮独立进程各 122 项真实游戏测试通过；用户客户端集中活动、原教员补课与具体人物知识、文书原生阅读与权限、真实材料／书册及保存退出再进入已核实，证据见 [阶段 8 验收记录](08-phase8-acceptance.md)。未开始阶段 9。阶段 7 的原设施、捐赠、案件、人物和物资继续保留，不重新创建教堂或重复发粮。

## 本地职责与持久闭环

`social.religion.life` 接入既有机构、产权、生产、人物知识与持久计划，不用阵营身份代替具体职权。

| 职位 | 窄权限 | 职责 |
|---|---|---|
| 主持者 `CLERGY_OFFICIANT` | 公共仪式、救济审查、婚丧见证 | 仪式、婚礼和丧礼记录；不自动处分一般财库或济贫物资 |
| 修士/修女 `COMMUNITY_RELIGIOUS` | 社区关怀 | 本人同意后的当面探访；不自动治病 |
| 抄写员/教员 `SCRIBE_TEACHER` | 公开教学、图书管理 | 实际教材授课、实际材料抄写 |
| 看守 `CHAPEL_WATCHMAN` | 场所维护、值守 | 指定位置的实际巡视、步道支撑检查与修补 |
| 地方代表 `TEMPLE_REPRESENTATIVE` | 地方协定谈判 | 当前代表权下签署具体地方协作条款 |

新增权限只追加，不改变旧权限序号。已有主持职位不静默升级；需要婚丧见证权时另行明确任职。职位不改写职业、家庭、玩家雇佣或私产。正常执行限实际存活、`PLANNED`、`WORK`、允许工作且无其他雇主的 NPC；玩家参加须本人签署邀请。

```text
有限日程／具体邀请
  → 本人同意、当前主持职权、独占本地场所
  → 实际路径到场（可超过 NPC 周围 20 格）
  → 每个实际作业 tick 核验教材、同意、视线与在场者
  → 实物／文书／具体人物知识结算
  → 散会、释放预留、下一职责或生活休整
```

同维度相邻场所互斥，包括不同本地教堂。未来预分配主持者不提前占用场所。受邀者实际进入站位，不能把宽松的远距交互范围当作入座。缺主持者、缺同意、少人、路线不可达、场所损坏、权限撤销等有明确原因、有限延期和截止取消，不用离线计时伪造完成。主持者死亡停止未完成活动；已经真实提交的结果只补收尾，不回滚后再造一份。

持久状态为 `PLANNED → ASSEMBLING → WORKING → SETTLING → COMPLETED`，异常可进入 `CANCELLED`／待核对。保存实际进度、固定人物身份、具体同意和各人的累计听课时长。紧急真实进食可抢占未结算工作并保存进度；日常工作时间边界仍适用。`PLANNED` 吟游诗人兼容角色不运行旧的无条件群体增益，`LEGACY` 行为不变。

## 教学、实物与文书

- 教员必须依法查阅本教堂实际存在的公开教材。学生须明确同意并实际听完所需时长，才取得带教材来源、时间和可信度的具体知识；缺席或迟到不足时长者不取得全文，不发抽象科技点。
- 抄本、婚礼记录册和丧礼记录册沿用真实生产批次：每册消耗 **3 纸、1 墨囊、1 皮革**。核验原产权、实物预留、作业和输出容量；输出满不先吃掉原料，释放空间后原批次仅结算一次。输出为带作者、文书编号和来源组件的真实成书。
- 婚礼需要双方明确同意和实际到场。记录仅证明仪式，不直接改写家庭配偶真值。丧礼须主持者具有来源明确的死亡报告；传闻不是全局死亡或墓葬事实，不自动杀死人物、埋葬遗体或分配遗产。
- 探访记录仅证明本人同意的会面，不自动治愈或公开病情。看守记录仅证明指定地点实际巡视，不从后台制造犯罪结论。
- 维护只修补指定步道下方的空气支撑空缺，消耗依法可用的真实圆石；不拆除或覆盖现有建筑，也不宣称全建筑维修完成。

`ChurchRecord` 固定作者、保管容器、时间、来源、当事人、可信度和权限。导入普通成书只登记实际正文，书上署名是未核实的来源标签，不认证其作者或内容为真。可信度不会因复制而变成全知事实。未提交的草稿不能对外查阅。

## 玩家知识与测试后台

到教堂接待处使用 `/saga church here`：显示本人的邀请和合法目录；点击邀请只是填入待确认命令，须按回车提交。目录不等于掌握全文。

普通入口：

```text
/saga church join <活动编号>
/saga church leave <活动编号>
/saga church read <文书编号>
/saga church known <教堂编号>
/saga church compact <教堂编号> <HOUSEHOLD|INSTITUTION> <对方编号> <有效ticks> <具体条款>
/saga church sign <协定编号> <true教堂一方|false对方>
/saga church complain <文书编号> <当地审理机构编号> <具体异议>
```

公开全文、公开目录、当事人专用、图书职务限定、机密分别核验。目录不显示机密正文；本人知识入口只读本人已有记录，不用后台当前状态覆盖历史听闻。原生右键阅读已登记的私密成书同样核验资格，不允许绕过命令查阅政策。普通未登记原版书不受统一封锁；本实现不是书本组件加密或恶意客户端防护。

权限 2 后台入口：`catalogue`、`schedule`、`npc-consent`、`cancel`、`calendar`、`death-report`、`audit`、`demo`、`demo-status`。`audit` 展示进度、人物、文书作者／保管者／来源等元数据，默认不输出私密正文。`npc-consent` 不能替玩家签名。显式测试证词不代表世界后台真值。

`calendar` 每批最多 14 次、每次最多 16 人，逐次邀请、同意和核验在场，不是永久仪式动画。`schedule` 完整参数：

```text
/saga church schedule <教堂> <RITE|LESSON|COPY|VISIT|MARRIAGE|FUNERAL|MAINTENANCE|WATCH> <x y z> <主体UUID|none> <教材UUID|none> <参与者选择器> <最低人数> <延迟ticks> <时间窗ticks> <实际作业ticks>
```

## 地方合作与争议

教堂可以与同聚落实际家庭、议事会、行会等订立具体双边协定。双方当前有代表权的人物须分别实际到场签署；保存原条款、双方签名人物、期限，不允许重放改变签名人。家庭按当前家长、机构按谈判职权核验。单方草案不算合作，签名不自动征用家庭物资、强制赴会或转移产权。

依法可查阅的特定文书可以作为当地争议证据，保存原文书编号和具体异议。受理不等于有罪，教会—机构关系可记录具体合作／争议，不改写所有人物的阵营归属，也不把冲突压成全局声望加减。账目不符或偏袒仍须具体证据和当地审理，不后台自动定罪。

## 存档与范围

独立 `sagadyssey_church_life_v3` 账本当前 schema 3，保存活动、文书、有限日程、个人在场时长、地方协定。活动／文书／日程／协定各限 4096，不静默驱逐未完成义务；重复、缺字段、孤立来源和没有匹配文书的完成状态拒绝加载，不把损坏账本当空白新世界。仅显式兼容本轮开发 schema 1/2；普通新世界无需迁移。

真实生产提交凭据与原文书匹配时，只恢复原结果与收尾，不再次扣料或复制成书。正常写盘与独立新进程恢复纳入必需测试；跨实体区块／多账本突然断电的完全原子性、百人规模、离线生产、完整 LOD、战斗及巡逻计划接入不在阶段 8 保证范围。

集中客户端夹具由测试者明确执行才创建，绝不在世界加载时自动运行。它只在空位新增六名测试人物、一本教材和 12 纸／4 墨／4 皮革，不覆盖原人物、方块或库存，不代玩家同意。创建意图先落账；重发不再加人或材料，部分创建中断必须核对而非无条件重放。完整客户端流程见验收记录。
