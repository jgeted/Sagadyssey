## R1：通过

支持 `vilg_2` 的版本化住宅模板、三名原居民和十二个明确作物位置，食物路线为直接食用胡萝卜。
初始投入为十六个胡萝卜、零成熟度的十二株作物、一把有限耐久铁斧和十八块可采原木。
四个储物设施初始为空；床位、真实湿润耕地、含水步行面和照明由模板生成。辅助湿润土壤不扩成额外播种位置。
没有用初始成品粮填满粮仓，没有加快随机刻，也不靠玩家维持生产。林工斧和木材有限，食品路线不依赖它们续供。

自然入口在新建普通地形世界中验证，种子 `7019`，发现位置 `(-1088, 86, -752)`。
它经过原版定位和实际区块生成，自动登记、创建居民和家庭；整个村庄身份与单栋住宅身份分开。
只处理实际成功放置的对象；旧的无标记结构不补登记，不扫描旧世界。

正式循环为 `society-r1-cycle-20261019-e`：168000 刻、21 次真实进食、同一作物点最多五次收获。
守恒式为 **16 + 100 = 95 + 21**，循环内每二十刻核对一次。
独立 JVM 重进原存档后，净作物投入产出从 100 到 105，进食从 21 到 22；原居民身份不变，仍严格对账。
最后 4096 个服务器刻的 p95 为 1.4868ms；总运行中三次超过 50ms 均在启动和最初加载阶段。
这是三名居民的机器实测，不外推为任意聚落数量的性能承诺。

普通玩家使用 `/saga society nearby`、`join`、`status`、`deliver`、`leave`。
交付四块橡木获得来自本户实际粮仓的两个胡萝卜，每人物每日最多一笔成功交付。
服务端以真实双向转移结算，重复请求、退出再加入不能重复领酬；未知中断进入待核对，不自动补发。
成员身份不会授予领主权或处分他人私人资产的权利，领取的食物可以按原版机制实际食用。

当前验收：519 项单元测试、3 项自然登记、3 项初始化与普通成员、7 项短缺与对照、6 项已有生活回归、1 项长周期、1 项独立重启，均通过；普通地形独立服务器另行通过。

修复了旧生产 Goal 与 PLANNED 并行、空粮仓伪进食计划阻挡补货，以及严重饥饿时本户食物运输的排班入口。

## R2：通过

M4：两聚落、六名原居民的登记农田和仓储采用唯一近处/远方权威。每步二百刻，每帧最多两步、循环预算二毫秒；未完时间保留为积压。原实体、旧货舱和既有义务不复制。远方内部供给经过一千二百刻实际游戏时间的批次预留和正式转移。

同一起始世界的三组二十四万刻比较通过：近处总收获 452、留种 121、库存 301、进食 62；两组远方均为收获 480、留种 120、库存 332、进食 60。各组初始可用食物均为 32，守恒分别为 32+452-121=301+62 与 32+480-120=332+60。远方与远方重启结果完全一致；相对近处的产量差 28，小于测试前冻结的 192；首次收获时间差小于冻结的 96000 刻。所有产量差均来自记录的模型规则。

收获前后、取货前后、交付前后的切换、未知中断停止重放和冲突镜像保留物资分别通过。独立 JVM 在卸载期间重启、保存的原有居民恢复及重复回调不重复投影均有原始记录。最后一次受影响回归的模型 p95 为 0.2821ms，交接最大 7.2772ms；交接单独计量，不声称每个交接低于二毫秒。

M5：版本化田作户与林业户按明确约定交换两块真实原木和四个胡萝卜，不宣称自由市场。原有运输者通过已有需求、产权、预留、货舱和交付服务实际往返。生产环境仅为这名运输者维持至多九个显式移动区块票据（原版传播的加载区块数量更多）；不扫描或强制加载全部聚落。断路时四个食物保留在原货舱、饥饿继续增长；恢复道路后有效交付。付款后携货期间独立 JVM 重启仍只结算一次。接收户变更住所时进入 REVIEW，保留四个在途食物与四个未清偿义务，不伪造交付。

### 自主发展与六人近远往返

正式场景 `society-r3-autonomous-20261019-b` 没有测试搬粮、人工成熟作物、关闭工作 AI 或注入饥饿。
NPC 自然生产后完成实物交换；原林业家庭根据真实剩余资源和有效寻路受阻记录自行申请迁居，三名原人实际到达，取得原作物所有者按接纳约定授予的供给权。
专用作物仓为迁入户保留八份种用储备；近处复用已有需求、预留与携货运输，远方使用原迁入者能力和一千二百刻批次，实际转移同一批作物。
个人背包、原私人仓库、公共物资与两个生活户的粮仓分开保留，迁居不复制或赠送财物。

场景推进 241559 个游戏刻，其中包含六万刻有界远方补算压力；不是全程逐帧运行，也不是现实停服补算。
新床由一块原木制成四块木板，其中三块木板加三块生成时明确投入的羊毛制成；施工另消耗四个实际胡萝卜，留下一个木板。
批准时实际粮仓为 16，家庭有权支配的实际余粮为 54；床位压力与结余均有记录，实际劳动满两百刻和四百刻后才完成两段制作。
区域食物严格守恒：

**32 + 138 + 54 = 168 + 34 + 18 + 4**

左边为初始食物、近处净生产和远方净生产；右边为返回后的实际库存、近处进食、远方进食和施工口粮。
两户和原六名人物返回后，原林业聚落常住人口为零，接纳聚落为六；远方仍有迁入户真实供给回执，没有“离村幽灵人口”。

实现中纠正了两个自然路径问题，并在上述正式场景前更新了契约：粮仓补货目标为 16，不能用“粮仓必须到 20”作为发展前提，改查保留种用储备后可合法支配的余粮，数值阈值仍为 20；林地尚有一块实际受阻原木时，不能把家庭永远锁在“全部采空”的迁居条件上，改用既有有效受阻记录判断当前工作机会，同时保留剩余和受阻数量。
那块木头没有被删除，也没有被计入已采产量。失效的受阻记录、未加载区块都不能当成“资源已空”。

### 公共决策与有限冲突

普通玩家沿用 `/saga society nearby`、`join`、`status`、`deliver`、`leave`；新增 `institutions` 查看组织和负责人，`relief` 提出有限公共食物申请，`peace` 提出止损请求。
申请需由有权 NPC 按真实成员关系、库存和当前条件核验；申请者不会获得公共仓库处分权或自动成为统治者。普通成员权限、原版打开/破坏仓库的旁路以及重复请求均有运行检查。

冲突只由已确认的实物预付、逾期义务和严重生活短缺接入，原兵员或实际补给不足时不能造军队。
正式场景有两名原参战者、四份实际口粮成本和一处真实伤口；不是只改关系分数。
独立 JVM 重进后继续 48200 刻，旧行动不重启、不再次扣粮，迟到的敌对伤害被拒绝；原四份未付食物债务仍存在。
明确命令或工作权威撤回时，行动停止，保留实际成本、原人当前位置和未归队事实，不能伪造归队或退款。
领土转移后置；本版没有围城、完整征服法律或无限战争规模。

继承后的同一项目、新床、旧负责人死亡事实和已结算公共支出，也在独立进程重启后验证保持一致。
未知的公共支出、施工或军需结算中断进入待核对；恢复测试验证不会用一个新意图重做旧支出。

## 当前支持边界

- 自然入口为 `vilg_2` 的三种版本化模板，每处三名原居民；首批四个已登记对象作为本版区域。旧无标记村庄不补登记，不扫描世界。
- 远方只推进登记的胡萝卜土地、库存、需求与约定供给；林业等未支持的物理作业保持实体或暂停，工具和木材有限。停服不按现实时间补算。
- 固定交换为两块橡木换四个胡萝卜；同时至多一笔活动商路、一个三人家庭迁居和一个有限冲突。活动窗口的显式票据上限分别为 9、27、18；原版传播加载的区块多于这些票据数。
- 每处只改善一张床；不扩成全部职业、技术树、全国财政、任意模组兼容或所有地形的寻路保证。自然居民的外部雇佣及跨维度生活未纳入这次验收。
- 未知货物、未清偿债务、受阻路线和缺失目的地保留真实状态，不自动退款、补粮、补人或把等待写成成功。
