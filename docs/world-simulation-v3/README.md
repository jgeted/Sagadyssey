# Sagadyssey 世界模拟 v3

v3 不推翻 v2 已经建立的人物、产权、知识、家庭、市场、制度与交易模型。它解决的是当前最明显的实现断层：领域数据已经存在，但 NPC 缺少统一、可恢复、可解释的计划执行主干。

## 已锁定的决定

1. 保留成熟领域服务，重写 NPC 行为编排层；
2. 一个 NPC 同时只能运行旧 Goal 或新计划内核，禁止双重结算；
3. 所有工作、等待和静止都必须有具体计划与原因；
4. 新 NPC 使用数据驱动角色和机构职位，不继续堆叠 `NpcProfession` 枚举；
5. `sagadyssey:church` 是广域阵营，本地教堂是有真实财产和职位的独立机构；
6. 旧科技点系统停用玩家入口，但保留旧存档数据兼容；
7. 铁匠是新行为内核的第一个纵向切片；
8. 玩家只看到角色能够知道的内容，测试模式才显示后台真值。
