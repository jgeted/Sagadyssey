## 2. 本轮已实现的基础

- `FieldworkSearchArea`：指定工作区的完整稳定索引，不根据 NPC 周围 20 格裁剪；坐标复制为不可变快照，拒绝 packed BlockPos 截断与体积溢出。
- `FieldworkScan`：按每 tick 预算检索，游标可保存；区分检索中、发现目标、已检索为空、未加载区域和暂缓目标。没有发现目标不会自动开始无期限随机探索；不会强制加载区块。
- `FieldworkData`：服务端保存游标、分 NPC/维度的限时不可达记忆、幂等作业回执。工作区变化重置游标，但不丢弃回执。回执不能静默容错或覆盖；存档已存在但无法读取时禁止退回空账本。
- `FieldworkCommitService`：单步骤单方块提交接口。复核权限、目标、预留、投入和精确产物容量后，提交方块、物品与物权、工具损耗、回执；失败尝试整体回滚。相同步骤重试复用既有回执，键相同但负载变化时安全失败。
- 回执列出投入/产出和工具损耗；播种/收获、搭建/回收是不同步骤。所有新增真值仅存在于服务端，不加入普通玩家界面或网络同步。

基础单元测试之外，真实适配器已接入 Minecraft 实体、方块、库存、物权及工具损耗，邻居更新与表现动作安排在成功回执后。真实游戏流程另行验证，不能用模拟适配器替代。覆盖正常保存重进，不承诺断电时多个存档文件同时原子写入。

## 3. 已完成职业迁移

3. 接入持久计划链：预留 → 移动到有效站位 → 作业 → 携带 → 使用统一转移服务入库/交付。失败与终态释放本计划资源，不清理其他 NPC 的预留；重载重新验证目标和导航。
4. 增加自动接单、范围完成判断、明确原因的有限休息/维护与下一任务；没有成熟作物、空工作区或仓库满时不能永久站立或无限探索。
5. 添加权限受限的测试者入口和后台审计；普通玩家只显示当面可观察或其确实知道的内容，不能泄露账本、预留或精确失败码。
