## 本轮发现与修复

1. Goal 资格刷新与每 tick 作业不一致，威胁出现后仍可能走到作业失败分支：在执行桥先处理真实威胁，保留原义务、释放预留；执行 Goal 按实际每 tick 更新。
2. 无范围限制的服务凭据使用空字符串维度，原护送判断误拒绝：按原合法空范围解释，但仍核验具体服务证明／人物／物流路线；没有借用新合同。
3. 输出满重试会清掉表现层物流标记：改为查询原持久路线的实际货物义务，不以外观标记结束保护。
4. 相邻区块实体尚未就绪时误判患者消失：等待原对象区块完成加载，有总期限；确认对象真正离场时仍取消，不替换患者。保存场景明确等待两个原区块，不手工增加进度。
5. GameTest 小模板边界墙与新集中空地冲突，且扩展区域只加载未进入实体 tick：只在隔离测试里清除框架边界、显式加载完整区域并等就绪；正式游戏保留完整空地检查，不拆玩家方块。
6. 飞行弹体可能离开小测试盒：连续收集实际生成的弹体 UUID，严格断言唯一一箭，不能把已飞走的实体误判为生成失败；没有放宽弹药守恒。
