## 进入与建立

1. 退出旧版本客户端，再双击项目根目录的 `Start-Sagadyssey.cmd`，进入原测试世界。不要删除或重建原世界。
2. 找一片平坦空地，离原教堂、桶和 NPC 稍远。命令使用当前站位往世界坐标 X、Z 正方向各偏移 2 格，需 **19×13 格**空站位、上方一格空气及实心地面；不是按照人物朝向布置。必要时先 `/time set 1000`，便于观察。
3. 只执行一次 `/saga combat demo`。这是权限等级 2 的测试入口，会明确新增 5 名测试人物、3 个桶、1 个铁砧和测试物资；所有权、劳动、路径、医疗同意和运输均走正式服务，不删除旧人物、不覆盖旧方块、不使用旧库存。重复执行只返回原记录，不重复生成。

## 集中观察

留在附近约一分钟，不暂停游戏，不搬走测试原料：

- 铁匠实际锻造一段 → 有限撤离到原发令玩家位置 → 返回同一个订单继续锻造，战斗／撤离时间不算劳动。
- 医师当面处理原患者和原伤口，实际消耗一份白色羊毛绷带，不直接补满 HP。
- 护卫保护实际运输员；运输员实际搬运 3 煤并存入目标桶，不能只凭名字或外观计为完成。

执行 `/saga combat demo-status`。期待锻造 `COMPLETED`、劳动 `400/400`、材料预留 `0`；医疗 `COMPLETED`、劳动 `400/400`、固定治疗回执 `true`；护送和有限撤离 `COMPLETED`；运输交付 `3/3`；同一订单续接 `true`，5 个原实体当前加载。可截图给开发者核对，不要反复创建新的夹具。

右键观察测试 NPC 的普通交互页面：不得出现全量后台订单／预留、患者私密伤口档案、他人合同或未知家庭真值。`demo-status` 是测试者后台，不能当作普通玩家已经知道的内容；普通账号没有该命令权限。无命令权限者的自动拒绝和本人命令记录隔离已单独测试，但不据此代替真人 UI 检查。
