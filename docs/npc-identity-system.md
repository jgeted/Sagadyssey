# NPC 社会身份体系

## 定位

社会身份是职业之外的第二维：职业决定 NPC 做什么，身份决定其社会地位、礼仪、服装品质、称谓、语气和招募方式。它不等同于职业熟练度（学徒至大师），也不等同于集团指挥等级。玩家使用相同身份结构，但保存在独立 Attachment 中。

本体系以约 1250–1350 年西欧和中欧为视觉基线。真实身份拆为两个字段：

- `SocialClass`：长期社会阶层——平民、自由民、市民、贵族、王族；
- `Office`：可授予、可撤销的职务——无、受誓职、地方统治者、高级统治者、最高统治者。

原来的七级线性身份仅作为视觉、语言档位与旧存档迁移简写，不再直接代表权力来源。

| 社会阶层 | 社会依据 | 直接招募 | 基础费用 |
| --- | --- | --- | --- |
| 平民 | 土地依附、手艺或短工 | 是 | ×1.00 |
| 自由民 | 人身自由、契约与财产资格 | 是 | ×1.15 |
| 市民 | 城镇身份、产业或行会关系 | 是 | ×1.50 |
| 贵族 | 家族、土地权利与特权 | 否 | — |
| 王族 | 王朝血缘与继承资格 | 否 | — |

| 职务级别 | 权力来源 | 直接招募 | 表现档位 |
| --- | --- | --- | --- |
| 无 | 仅保留社会阶层 | 随阶层 | 平民 / 自由民 / 市民 / 贵族 |
| 受誓职 | 誓约、任命或组织成员身份 | 仅可招募平民、自由民、市民，阶层费用再 ×1.75 | 骑士式罩袍与抚胸礼 |
| 地方统治者 | 庄园、修院、行会或聚落治理权 | 否 | 领主式披肩与示意 |
| 高级统治者 | 区域性世俗或制度权力 | 否 | 公爵式长披风与回应 |
| 最高统治者 | 阵营最高职务 | 否 | 王室长袍与挥手 |

## 阵营称谓

相同 `Office` 会根据阵营显示不同称谓：

| 职务级别 | 王国 | 教会 | 商会 | 劫掠者 | 玩家阵营 |
| --- | --- | --- | --- | --- | --- |
| 受誓职 | 王国骑士 | 教团骑士 | 行会成员 | 劫掠者 | 家臣 |
| 地方统治者 | 男爵 | 修院长 | 行会长 | 匪帮头目 | 总管 |
| 高级统治者 | 公爵 | 主教 | 城市执政官 | 大首领 | 总督 |
| 最高统治者 | 国王 | 首席主教 | 商盟领袖 | 战王 | 君主 |

矮人、秘法学会与荒野阵营也有对应称谓；未知数据包阵营使用通用受誓者/领主/统治者称谓。

## 核心规则

1. 工作经验不会提升社会身份。身份晋升应来自城镇资格、效忠、授封、婚姻、领地或剧情事件。
2. 平民、自由民、市民可以直接招募；自由民担任受誓职时仍可招募但费用更高。贵族、王族及地方统治者以上职务不能用绿宝石购买。
3. 转职不改变身份，身份变化也不重置职业经验、背包或装备。
4. 骑士身份不自动附送盔甲；盔甲仍由装备槽决定。
5. 王冠、冠冕、权杖、印玺和礼仪佩剑均保留为独立物品，不进入身份模型。
6. 当前数据层允许管理员生成多个国王，方便开发测试；正式的“一阵营一国王”、继承与废黜应由未来王国/领地注册表统一约束，不能仅靠已加载实体扫描实现。
7. 交互礼仪比较 NPC 与玩家的实际优先级：对上位者躬身、同级按自身身份行礼、对下位者采用克制示意；玩家默认为平民且无职务。
8. 旧存档中的 `SocialStatus` 会在实体加载时静默迁移为 `SocialClass + Office`。

## 资源组合

运行时不再把人物、职业与身份塞进同一张贴图，而是分为三个可组合层：

- `128×64` 基础/职业贴图：标准 slim 身体与职业配件；
- `64×32` 人物层：男性、女性各六组脸型、肤色、发色、胡须、辫发、头巾或面纱；
- `64×64` 身份层：七档身份分别拥有男女完整服装，覆盖躯干、袖子和下装。

性别只影响外观，不改变碰撞箱、属性、职业或装备能力。职业配件、身份服装、护甲和手持物在渲染时独立组合，因此仍不需要维护 `职业 × 身份 × 性别 × 脸型` 的组合贴图。

## 文本语域

每级表现档位均有三类本地化文本：首次交互问候、接受指令、完成交易。低阶身份语句更直接、生活化；市民强调契约与账目；骑士强调誓约和荣誉；贵族强调家政与领地秩序；国王使用王国和王冠的制度性表述，而不是现代口语或夸张的奇幻腔。问候还会按玩家相对地位增加尊称或上位者示意。

## 开发命令

管理员可以使用：

```text
/saga npc spawn <profession> <faction> <social_status>
/saga npc status <npc选择器> <social_status>
/saga npc identity <npc选择器> <social_class> <office>
/saga npc appearance <npc选择器> <gender> <face>
/saga npc showcase [profession] [faction]
/saga identity get [player]
/saga identity set <player> <social_class> <office> [title_faction]
```

例如：

```text
/saga npc spawn TRADER merchant_guild BURGHER
/saga npc spawn WARRIOR kingdom KNIGHT
/saga npc spawn NONE kingdom KING
/saga npc status @e[type=sagadyssey:npc_base,limit=1,sort=nearest] DUKE
/saga npc identity @e[type=sagadyssey:npc_base,limit=1,sort=nearest] NOBLE HIGH_RULER
/saga npc appearance @e[type=sagadyssey:npc_base,limit=1,sort=nearest] FEMALE WEATHERED
/saga npc showcase WARRIOR kingdom
/saga identity set @s ROYAL SOVEREIGN kingdom
```

`showcase` 会以男女两排生成 `COMMONER → KING` 共十四个表现样本，并立即播放各自的礼仪动作，适合检查脸型、身份服装、职业配件与原版护甲是否正确分层。
